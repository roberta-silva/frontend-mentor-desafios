# Soluções Frontend Mentor ✨

Este repositório reúne minhas soluções para os desafios do [Frontend Mentor](https://www.frontendmentor.io/).

Aqui você vai encontrar projetos organizados em pastas separadas, cada uma contendo a solução de um desafio.
Cada projeto está organizado em sua própria pasta e foi desenvolvido seguindo **boas práticas de acessibilidade, semântica, design responsivo e código limpo**, destacando meu compromisso com **qualidade, organização e experiência do usuário**.

## 🔹 Projetos disponíveis

1. **[Interactive Rating Component](./interactive-rating-component/)**  
   `HTML` · `CSS` · `JavaScript`  
   Componente interativo de avaliação onde o usuário seleciona uma nota e envia o feedback, com foco em **eventos**, **gerenciamento de estado da interface**, **feedback visual** e acessibilidade.

2. **[FAQs Accordion](./faq-accordion/)**  
   `HTML` · `CSS` · `JavaScript`  
   Página de FAQ com **accordion interativo**, desenvolvida para praticar **manipulação do DOM**, controle de estados visuais e criação de interfaces claras e responsivas.

3. **[Results Summary Component](./results-summary-component/)**  
   `HTML` · `CSS`  
   Componente de resumo de resultados criado para praticar **Flexbox**, **layout responsivo**, **organização visual de dados** e aplicação consistente de estilos.

4. **[Recipe Page](./recipe-page/)**  
   `HTML` · `CSS`  
   Página de receita estruturada com **HTML semântico** e **CSS flexível**, utilizando abordagem **mobile-first** e priorizando legibilidade, hierarquia visual e usabilidade.

5. **[Social Links Profile](./social-links-profile/)**  
   `HTML` · `CSS`  
   Página de perfil com links sociais, desenvolvida para exercitar **organização de conteúdo**, **centralização de layout**, **acessibilidade** e boas práticas de CSS responsivo.

6. **[Blog Preview Card](./blog-preview-card/)**  
   `HTML` · `CSS`  
   Cartão de prévia de blog criado para praticar **estruturação semântica**, **tipografia acessível** e **layout responsivo**, com foco em clareza visual e design moderno.

## 🔹 Objetivo deste repositório

Apresentar soluções Front-end de alta qualidade que combinam **boa prática de código, acessibilidade e design responsivo**, mostrando minha capacidade de **resolver problemas reais e criar interfaces funcionais e eficientes**.
